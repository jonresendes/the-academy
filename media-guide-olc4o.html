How to add a picture or video so students see it
  1. Open olc4o.js and find the lesson (search for the slot's title).
  2. Paste the image URL or the video link into that slot's src: ''. YouTube links become an embedded player; images show under the slide; any other link shows as a button.
  3. Upload the course file again and bump VERSION in sw.js. Until a slot has a src, students never see it — only an unlocked teacher sees the dashed placeholder on the slide.

Tip: for images, Wikimedia Commons file pages have a “Use this file → URL” link; for CrashCourse / Heritage Minutes use the YouTube “Share” link. This checklist is also in the app under Settings → Teacher Lock → Media checklist.
